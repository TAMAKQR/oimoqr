# 📸 Улучшения системы загрузки изображений

## ✨ Что было улучшено

### 1. **Автоматическое сжатие изображений**
- Большие изображения (>1 МБ) автоматически сжимаются перед загрузкой
- Сохранение пропорций и качества изображения
- Адаптивное качество: если размер превышает лимит, качество снижается автоматически
- Показ процента экономии места

**Параметры сжатия:**
- **Логотипы**: до 800×800px, качество 90%, макс. 0.5 МБ
- **Баннеры**: до 1920×800px, качество 85%, макс. 1 МБ

### 2. **Drag & Drop загрузка**
- Просто перетащите изображение в область загрузки
- Визуальная обратная связь при перетаскивании
- Работает на всех устройствах с поддержкой drag & drop

### 3. **Улучшенный UI/UX**
- Красивая область загрузки с иконкой
- Превью изображения сразу после выбора
- Показ размера файла (до и после сжатия)
- Индикатор процесса сжатия
- Информация о рекомендуемых размерах

### 4. **Валидация**
- Проверка типа файла (JPEG, PNG, GIF, WebP)
- Проверка размера файла (макс. 10 МБ)
- Понятные сообщения об ошибках

## 📁 Новые файлы

### `frontend/src/utils/imageCompression.js`
Утилита для работы с изображениями:
- `compressImage()` - сжимает изображение
- `formatFileSize()` - форматирует размер в читаемый вид
- `validateImage()` - валидирует изображение
- `shouldCompress()` - проверяет, нужно ли сжатие

### `frontend/src/components/ImageUploader.jsx`
Универсальный компонент для загрузки изображений:
- Drag & Drop интерфейс
- Автоматическое сжатие
- Превью изображения
- Показ размера файла

## 🔧 Использование

### Базовое использование

```jsx
import ImageUploader from '../components/ImageUploader';

<ImageUploader
  onFileSelect={(file) => setSelectedFile(file)}
  label="Загрузите изображение"
  maxSizeMB={10}
  compressOptions={{
    maxWidth: 1920,
    maxHeight: 1080,
    quality: 0.85,
    maxSizeMB: 1
  }}
/>
```

### Параметры компонента

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `onFileSelect` | Function | - | Callback при выборе файла |
| `accept` | String | 'image/*' | Допустимые типы файлов |
| `maxSizeMB` | Number | 10 | Макс. размер до валидации |
| `compressOptions` | Object | {} | Настройки сжатия |
| `label` | String | 'Загрузить изображение' | Текст в области загрузки |
| `showPreview` | Boolean | true | Показывать превью |
| `currentImage` | String | null | URL текущего изображения |
| `disabled` | Boolean | false | Отключить загрузку |

### Параметры сжатия

```javascript
{
  maxWidth: 1920,      // Макс. ширина в пикселях
  maxHeight: 1080,     // Макс. высота в пикселях
  quality: 0.85,       // Качество JPEG (0-1)
  maxSizeMB: 1         // Целевой размер в МБ
}
```
