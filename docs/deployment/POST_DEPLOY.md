# 🎉 После деплоя OimoQR

Поздравляем! Ваш OimoQR успешно задеплоен на **oimoqr.com**. Вот что нужно сделать дальше.

---

## ✅ Немедленные действия (первые 24 часа)

### 1. Проверьте работоспособность

```powershell
# Проверьте DNS
nslookup oimoqr.com
nslookup api.oimoqr.com

# Проверьте SSL
# Откройте в браузере и убедитесь в наличии зеленого замка:
# https://oimoqr.com
# https://api.oimoqr.com/health
```

### 2. Создайте первого администратора

Если еще не создали:

```powershell
# Подключитесь к production БД (используя External URL от Render)
$env:DATABASE_URL="ваш-render-external-url"

# Создайте админа
Set-Location "d:\QR MENU\backend"
npm run create-admin admin@oimoqr.com SecurePassword123 "Admin Name"
```

### 3. Войдите в админ-панель

1. Откройте `https://oimoqr.com/login`
2. Войдите с учетными данными админа
3. Перейдите в `https://oimoqr.com/admin`
4. Убедитесь, что панель работает

### 4. Создайте тестовый ресторан

1. Откройте `https://oimoqr.com/register`
2. Зарегистрируйте тестовый ресторан:
   - Субдомен: `demo`
   - Название: "Demo Restaurant"
3. Добавьте несколько категорий и блюд
4. Загрузите фотографии
5. Откройте `https://demo.oimoqr.com`
6. Проверьте, что меню отображается корректно

### 5. Протестируйте заказ

1. Откройте меню тестового ресторана
2. Добавьте блюда в корзину
3. Нажмите "Оформить заказ"
4. Проверьте, что WhatsApp открывается с правильным сообщением

## 🔒 Безопасность (первая неделя)

### 1. Смените дефолтные пароли

```powershell
# Смените пароль админа
# Войдите в админ-панель и обновите пароль
```

### 2. Настройте backup базы данных

**Render на бесплатном плане НЕ делает автоматических бэкапов.**

**Решение:**
1. **Перейдите на платный план** ($20/месяц за DB) для автоматических бэкапов.
2. **Делайте ручные бэкапы** с помощью `pg_dump` и External Connection URL.
   - `pg_dump "YOUR_EXTERNAL_DB_URL" > backup.sql`

### 3. Проверьте environment variables

Убедитесь, что секреты не попали в Git:

```powershell
# Проверьте историю коммитов
git log --all --full-history --source -- **/.env

# Если нашли .env в истории, удалите:
# https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/removing-sensitive-data-from-a-repository
```

### 4. Включите 2FA на всех платформах

- GitHub: Settings → Password and authentication → Two-factor authentication
- Vercel: Settings → Security → Two-Factor Authentication
- Render: Account Settings → Security

## 📈 Оптимизация (первый месяц)

### 1. Настройте CDN для изображений

**Проблема**: Render free tier имеет ephemeral storage (файлы удаляются при перезапуске).

**Решение**: Интегрируйте Cloudinary (бесплатно до 25GB):

1. Зарегистрируйтесь на [cloudinary.com](https://cloudinary.com)
2. Получите API credentials
3. Обновите backend для загрузки в Cloudinary
4. Миграция существующих файлов

### 2. Оптимизируйте изображения

- Используйте WebP формат
- Сжимайте изображения перед загрузкой
- Настройте lazy loading

### 3. Настройте кеширование

В `backend/src/server.js` добавьте кеширование для статики:

```javascript
app.use(
  "/uploads",
  express.static(join(__dirname, "../uploads"), {
    maxAge: "7d",
    etag: true,
  })
);
```

### 4. Мониторьте производительность

- Используйте Lighthouse для аудита
- Проверяйте Core Web Vitals
- Оптимизируйте медленные запросы к БД

## 📊 KPI для отслеживания

### Технические метрики

- **Uptime**: > 99.5%
- **Response time**: < 500ms
- **Error rate**: < 1%
- **Database size**: < 400MB (80% от лимита)

### Бизнес метрики

- **Регистрации**: количество новых ресторанов
- **Конверсия trial → paid**: % оплативших после trial
- **Churn rate**: % отказавшихся от подписки
- **MRR** (Monthly Recurring Revenue): месячный доход
- **CAC** (Customer Acquisition Cost): стоимость привлечения клиента
- **LTV** (Lifetime Value): пожизненная ценность клиента

### Пользовательские метрики

- **DAU/MAU**: активные пользователи
- **Просмотры меню**: количество просмотров
- **Заказы**: количество заказов через WhatsApp
- **Среднее время на сайте**

## 🚀 Масштабирование

### Когда переходить на платные планы?

**Vercel Pro** ($20/мес) - когда:

- Bandwidth > 80GB/месяц
- Нужна расширенная аналитика
- Нужна поддержка команды

**Render Starter** ($7/мес) - когда:

- Backend часто засыпает (плохой UX)
- Нужна стабильная производительность
- > 10 активных ресторанов
 
**Render DB Starter** ($20/мес) - когда:

- Database size > 800MB
- Нужны автоматические бэкапы
- Приближается 90-дневный лимит бесплатного плана

### Когда нужен dedicated сервер?

- > 100 активных ресторанов
- > 10,000 просмотров меню в день
- Нужна кастомная инфраструктура
- Специфические требования к безопасности
