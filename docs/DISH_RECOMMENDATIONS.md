# Система рекомендаций блюд

## 📋 Описание

Интеллектуальная система рекомендаций блюд с гибридным подходом для увеличения среднего чека и cross-selling.

## 🎯 Возможности

### 1. Приоритетная система рекомендаций (4 уровня):

1. **Статистика заказов** (приоритет 1)
   - Анализ реальных данных: "С этим блюдом часто заказывают..."
   - Минимальный порог: 3 совместных заказа
   - Автоматическое обновление на основе поведения клиентов

2. **Ручные рекомендации** (приоритет 2)
   - Владелец ресторана выбирает блюда в админке
   - Работает с первого дня без истории заказов
   - Возможность настроить до N блюд для каждого

3. **Похожие из категории** (приоритет 3)
   - Блюда из той же категории
   - Сортировка по порядку и дате создания

4. **Популярные блюда** (приоритет 4)
   - Наиболее заказываемые блюда ресторана
   - Fallback когда нет других вариантов

### 2. UI/UX для клиентов

- Секция "С этим блюдом часто заказывают" в модалке блюда
- Горизонтальный скролл с превью (фото, название, цена)
- Клик по рекомендации открывает это блюдо
- Ленивая загрузка изображений

### 3. Админка для управления

- Checkbox-список всех блюд ресторана при редактировании
- Показ выбранных рекомендаций (счетчик)
- Исключение текущего блюда из списка
- Автосохранение при обновлении блюда

## 🔌 API Endpoints

### GET `/api/dishes/:dishId/recommendations?limit=4`

**Публичный endpoint** для получения рекомендаций.

**Query параметры:**
- `limit` - количество рекомендаций (default: 4)

**Response:**
```json
{
  "dishId": "clxxx...",
  "recommendations": [
    {
      "id": "clyyy...",
      "name": "Пицца Маргарита",
      "price": 450,
      "image": "https://...",
      "categoryId": "clzzz...",
      "recommendationType": "statistics" // или "manual", "category", "popular"
    }
  ]
}
```

### PUT `/api/dishes/:id`

**Обновлено:** Теперь принимает `recommendationIds` (массив ID блюд).

**Request body:**
```json
{
  "name": "Пицца Пепперони",
  "price": 550,
  "recommendationIds": ["dish-id-1", "dish-id-2", "dish-id-3"]
}
```

3. Выбрать блюда из списка (checkbox)
4. Сохранить блюдо

## 🎬 Использование клиентами

1. Открыть блюдо на странице меню
2. Посмотреть секцию "💡 С этим блюдом часто заказывают"

4. Добавить в корзину
