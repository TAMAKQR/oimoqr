# 📚 Библиотека модификаторов (Modifier Templates)

## 🎯 Назначение

Система шаблонов модификаторов позволяет создавать модификаторы один раз и применять их к разным блюдам, а также обновлять все связанные модификаторы одной кнопкой.

---

## 🗄️ База данных

### Новые таблицы:

1. **ModifierTemplate** - Шаблоны модификаторов на уровне ресторана
2. **ModifierTemplateOption** - Опции шаблонов
3. **Modifier.templateId** - Связь модификатора с шаблоном (новое поле)

### Миграция:

```bash
cd backend
# Применить миграцию на локальной БД
psql $DATABASE_URL -f migrations/add_modifier_templates.sql

# Или через Prisma
npx prisma db push
npx prisma generate
```

## 📡 API Endpoints

### 1. Получить все шаблоны ресторана

```http
GET /api/modifiers/restaurant/:restaurantId/templates
Authorization: Bearer <token>
```

**Response:**
```json
[
  {
    "id": "template123",
    "name": "Подогрев",
    "type": "single",
    "isRequired": true,
    "restaurantId": "rest123",
    "options": [
      { "id": "opt1", "name": "Подогреть", "price": 0 },
      { "id": "opt2", "name": "Не подогревать", "price": 0 }
    ],
    "_count": {
      "usedInModifiers": 45  // Используется в 45 блюдах
    }
  }
]
```

---

### 2. Создать шаблон модификатора

```http
POST /api/modifiers/templates
Authorization: Bearer <token>
Content-Type: application/json

{
  "name": "Подогрев",
  "type": "single",
  "isRequired": true,
  "restaurantId": "rest123",
  "options": [
    { "name": "Подогреть", "price": 0 },
    { "name": "Не подогревать", "price": 0 }
  ]
}
```

---

### 3. Обновить шаблон

```http
PUT /api/modifiers/templates/:id
Authorization: Bearer <token>
Content-Type: application/json

{
  "name": "Подогрев (обновлено)",
  "type": "single",
  "isRequired": false,
  "options": [
    { "name": "Горячее", "price": 0 },
    { "name": "Холодное", "price": 0 },
    { "name": "Комнатная температура", "price": 0 }
  ]
}
```

**Важно:** После обновления шаблона нужно синхронизировать модификаторы!

---

### 4. Применить шаблон к блюду

```http
POST /api/modifiers/templates/apply
Authorization: Bearer <token>
Content-Type: application/json

{
  "templateId": "template123",
  "dishId": "dish456"
}
```

**Response:**
```json
{
  "id": "modifier789",
  "name": "Подогрев",
  "type": "single",
  "isRequired": true,
  "dishId": "dish456",
  "templateId": "template123",
  "options": [...]
}
```

---

### 5. Синхронизировать все модификаторы с шаблоном

**Важнейшая функция!** Обновляет все модификаторы, созданные из этого шаблона.

```http
POST /api/modifiers/templates/:id/sync
Authorization: Bearer <token>
```

**Response:**
```json
{
  "message": "Обновлено 45 модификаторов",
  "count": 45
}
```

---

### 6. Удалить шаблон

```http
DELETE /api/modifiers/templates/:id
Authorization: Bearer <token>
```

**Примечание:** Нельзя удалить шаблон, если он используется в блюдах.

## 💡 Примеры использования

### Сценарий 1: Создание типичного модификатора для всех блюд

1. **Создаем шаблон "Подогрев":**
   ```json
   POST /api/modifiers/templates
   {
     "name": "Подогрев",
     "type": "single",
     "isRequired": true,
     "restaurantId": "rest123",
     "options": [
       { "name": "Подогреть", "price": 0 },
       { "name": "Не подогревать", "price": 0 }
     ]
   }
   ```

2. **Применяем к 50 блюдам:**
   ```javascript
   dishes.forEach(dish => {
     fetch('/api/modifiers/templates/apply', {
       method: 'POST',
       body: JSON.stringify({
         templateId: 'template123',
         dishId: dish.id
       })
     });
   });
   ```

3. **Изменили требования - теперь не обязательный:**
   ```json
   PUT /api/modifiers/templates/template123
   {
     "isRequired": false
   }
   ```

4. **Обновляем все 50 блюд одной кнопкой:**
   ```json
   POST /api/modifiers/templates/template123/sync
   ```

✅ Готово! Все 50 блюд обновлены!

---

### Сценарий 2: Размеры напитков

1. **Создаем шаблон "Объем":**
   ```json
   {
     "name": "Объем",
     "type": "single",
     "isRequired": true,
     "options": [
       { "name": "0.33л", "price": 0 },
       { "name": "0.5л", "price": 50 },
       { "name": "1л", "price": 100 }
     ]
   }
   ```

2. **Применяем к всем напиткам**

3. **Изменили цены:**
   ```json
   {
     "options": [
       { "name": "0.33л", "price": 0 },
       { "name": "0.5л", "price": 70 },
       { "name": "1л", "price": 130 }
     ]
   }
   ```

4. **Синхронизируем** - все цены обновлены!

## ⚠️ Важные моменты

1. **Связь с шаблоном сохраняется** - модификатор помнит, из какого шаблона он создан
2. **Синхронизация не автоматическая** - нужно нажать кнопку "Синхронизировать"
3. **Нельзя удалить используемый шаблон** - сначала отвяжите все блюда
4. **Изменения в отдельном модификаторе не влияют на шаблон** - это односторонняя связь
