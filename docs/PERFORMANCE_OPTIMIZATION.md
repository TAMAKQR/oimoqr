# ⚡ Оптимизация производительности загрузки меню

## 🐛 Проблема

Меню загружается очень долго (5-10+ секунд), что негативно влияет на пользовательский опыт.

## ✅ Решения

### 1. **Логирование производительности** 📊

Добавлено подробное логирование времени выполнения запросов на backend:

```javascript
⏱️ [Menu Load] Starting for subdomain: restaurant-name
⏱️ [Menu Load] Restaurant base: 150ms
⏱️ [Menu Load] Subscription check: 45ms
⏱️ [Menu Load] Categories & dishes: 2300ms  // ⚠️ Самый медленный!
⏱️ [Menu Load] ✅ TOTAL TIME: 2495ms
```

### 2. **Индексы базы данных** 🗄️

Созданы индексы для оптимизации запросов:

**Применение индексов:**
```bash
cd backend
npm run apply:indexes
```

**Созданные индексы:**
- `Restaurant_subdomain_idx` - быстрый поиск ресторана
- `Category_restaurantId_order_idx` - сортировка категорий
- `Dish_categoryId_order_idx` - сортировка блюд
- `Dish_restaurantId_available_idx` - фильтр доступных блюд
- `Modifier_dishId_order_idx` - модификаторы
- `DishTranslation_dishId_languageCode_idx` - переводы
- `Subscription_restaurantId_status_idx` - проверка подписки

**Ожидаемое ускорение:** 40-60%

### 3. **Кэширование на фронтенде** 💾

Добавлено кэширование меню на 5 минут:

```javascript
// Автоматически кэшируется
const data = await restaurantService.getBySubdomain(subdomain, language);

// Кэш автоматически очищается при обновлении
await restaurantService.updateRestaurant(id, data);
```

**Преимущества:**
- ✅ Мгновенная загрузка при повторном посещении
- ✅ Экономия трафика
- ✅ Снижение нагрузки на сервер
- ✅ Автоматическая очистка истекших данных

### 4. **Оптимизация запросов** 🔧

**До:**
- Множественные include на всех уровнях
- Загрузка всех данных сразу
- Нет фильтрации на уровне БД

**После:**
- Разделение запросов на этапы
- Фильтрация переводов на уровне БД
- Загрузка только доступных блюд
- Асинхронная запись просмотров

| Этап | До | После | Улучшение |
|------|-----|--------|-----------|

## 🚀 Применение на production

### 1. Применить индексы:

```bash
# На production сервере
cd backend
npm run apply:indexes
```

### 2. Перезапустить backend:

```bash
pm2 restart backend
# или
npm run start
```

### 3. Очистить кэш браузера:

Пользователи должны обновить страницу (Ctrl+F5) для получения новой версии.

## ⚠️ Известные ограничения

### Кэш на фронтенде:

**Проблема:** Изменения в меню не видны сразу

**Решение:** 
- Кэш автоматически истекает через 5 минут
- При обновлении меню через админку кэш очищается
- Можно очистить кэш вручную: `localStorage.clear()`

### Индексы БД:

**Проблема:** Занимают дополнительное место

**Решение:**
- Индексы занимают ~5-10% от размера БД
- Это нормально и оправдано ускорением
