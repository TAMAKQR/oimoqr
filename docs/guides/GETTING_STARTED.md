# 🎯 Начало работы с QR Menu SaaS

> Простое пошаговое руководство для абсолютных новичков

---

## 👋 Добро пожаловать!

Это руководство поможет вам запустить QR Menu SaaS на вашем компьютере за **10 минут**, даже если вы никогда раньше не работали с подобными проектами.

---

## ✅ Что вам понадобится?

Перед началом убедитесь, что у вас установлено:

### 1. Node.js (версия 18 или выше)

**Проверка:**

```powershell
node --version
```

**Если не установлен:**

- Скачайте с https://nodejs.org/
- Установите LTS версию
- Перезапустите терминал

---

### 2. PostgreSQL (версия 14 или выше)

**Проверка:**

```powershell
psql --version
```

**Если не установлен:**

**Вариант A: Локальная установка**

- Скачайте с https://www.postgresql.org/download/
- Установите с настройками по умолчанию
- Запомните пароль для пользователя `postgres`

**Вариант B: Docker (рекомендуется)**

```powershell
docker run -d -p 5432:5432 -e POSTGRES_PASSWORD=postgres --name qrmenu-db postgres:14
```

---

### 3. Git

**Проверка:**

```powershell
git --version
```

**Если не установлен:**

- Скачайте с https://git-scm.com/
- Установите с настройками по умолчанию

## 🚀 Шаг 1: Получите код

3. Выберите "Download ZIP"

5. Откройте папку в терминале

```powershell

npm install
```

**Что происходит?**

- Устанавливаются библиотеки для frontend
- Устанавливаются библиотеки для backend
- Создаются необходимые папки

**Ожидаемый результат:**

```
✓ Frontend dependencies installed
✓ Backend dependencies installed
```

## ⚙️ Шаг 3: Настройте переменные окружения

### 3.1 Frontend

```powershell
# Скопируйте пример файла
Copy-Item frontend\.env.example frontend\.env
```

**Откройте файл `frontend\.env` и измените:**

```env
VITE_API_URL=http://localhost:3000/api
```

Это всё! Для локальной разработки больше ничего менять не нужно.

---

### 3.2 Backend

```powershell
# Скопируйте пример файла
Copy-Item backend\.env.example backend\.env
```

**Откройте файл `backend\.env` и измените:**

```env
# База данных
DATABASE_URL="postgresql://postgres:postgres@localhost:5432/qrmenu?schema=public"

# JWT секрет (можете оставить как есть для разработки)
JWT_SECRET="your-super-secret-jwt-key-change-in-production"

# Email (для разработки можно использовать Mailtrap)
SMTP_HOST="smtp.mailtrap.io"
SMTP_PORT=2525
SMTP_USER="your-mailtrap-username"
SMTP_PASS="your-mailtrap-password"
SMTP_FROM="noreply@qrmenu.com"

# URL приложения
FRONTEND_URL="http://localhost:5173"
BACKEND_URL="http://localhost:3000"
```

**Важно:**

- Если вы используете Docker для PostgreSQL, оставьте `DATABASE_URL` как есть
- Если вы установили PostgreSQL локально, измените пароль на тот, который вы установили
- Для email можно создать бесплатный аккаунт на https://mailtrap.io/

---

## 🗄️ Шаг 4: Настройте базу данных

```powershell
# Перейдите в папку backend
Set-Location backend

# Примените миграции (создайте таблицы)
npx prisma migrate dev

# Заполните базу тестовыми данными
npx prisma db seed

# Вернитесь в корневую папку
Set-Location ..
```

**Что происходит?**

- Создаются таблицы в базе данных
- Создаются тестовые аккаунты:
  - Владелец: `test@restaurant.com` / `test123`
  - Админ: `admin@qrmenu.com` / `admin123`
- Создается тестовое меню

**Ожидаемый результат:**

```
✓ Database migrations applied
✓ Seed data created
```


- Запускается backend на http://localhost:3000
- Запускается frontend на http://localhost:5173
- Оба сервера работают одновременно

**Ожидаемый результат:**

```
Backend running on http://localhost:3000
Frontend running on http://localhost:5173
```

## 🐛 Возникли проблемы?

### Проблема: "Cannot connect to database"

**Решение:**

1. Проверьте, что PostgreSQL запущен:

   ```powershell
   # Для Docker
   docker ps

   # Для локальной установки
   Get-Service postgresql*
   ```

2. Проверьте `DATABASE_URL` в `backend\.env`

3. Попробуйте пересоздать базу:
   ```powershell
   Set-Location backend
   npx prisma migrate reset
   npx prisma db seed
   ```

---

### Проблема: "Port 3000 is already in use"

**Решение:**

1. Найдите процесс, использующий порт:

   ```powershell
   Get-NetTCPConnection -LocalPort 3000
   ```

2. Остановите процесс или измените порт в `backend\.env`:
   ```env
   PORT=3001
   ```

---

### Проблема: "Module not found"

**Решение:**

1. Удалите папки `node_modules`:

   ```powershell
   Remove-Item -Recurse -Force frontend\node_modules
   Remove-Item -Recurse -Force backend\node_modules
   ```

2. Переустановите зависимости:
   ```powershell
   npm install
   ```

---

### Проблема: Email не отправляются

**Решение:**

1. Для разработки это нормально - email опциональны
2. Если хотите тестировать email:
   - Создайте аккаунт на https://mailtrap.io/
   - Скопируйте SMTP настройки
   - Вставьте в `backend\.env`
