# Функционал просмотра клиентов ресторана

## Описание

Владельцы ресторанов теперь могут видеть список всех зарегистрированных клиентов через новую страницу "Клиенты" в панели управления.

## Реализованные возможности

### Backend

**Новый эндпоинт:** `GET /api/restaurants/:restaurantId/customers`

**Доступ:** Только владельцы ресторана и сотрудники

**Возвращает:**
- Список клиентов с их профилями
- Статистику заказов каждого клиента
- Любимые блюда
- Сохраненные адреса

**Пример ответа:**
```json
{
  "customers": [
    {
      "id": "customer_id",
      "phone": "+79991234567",
      "name": "Иван Иванов",
      "email": "ivan@example.com",
      "avatar": "https://...",
      "createdAt": "2025-01-08T12:00:00Z",
      "orders": [...],
      "favoriteDishes": [...],
      "savedAddresses": [...],
      "stats": {
        "totalOrders": 15,
        "totalSpent": 12500,
        "lastOrderDate": "2025-01-07T18:30:00Z"
      }
    }
  ],
  "total": 42
}
```

### Frontend

**Новая страница:** `/customers/:restaurantId`

**Функционал:**
- 📊 **Статистика:** Общее количество клиентов, заказов и сумма
- 🔍 **Поиск:** По имени, телефону или email
- 🔀 **Сортировка:** По дате регистрации, количеству заказов, сумме, последнему заказу
- 📋 **Таблица клиентов** с информацией:
  - Аватар и имя
  - Контакты (телефон, email)
  - Количество заказов
  - Общая потраченная сумма
  - Дата последнего заказа
  - Дата регистрации
  - Избранные блюда

**Навигация:** Добавлена ссылка в боковое меню (иконка 🧑‍🤝‍🧑 "Клиенты")

## Использование

1. Войдите в панель управления
2. Выберите ресторан из выпадающего списка
3. В боковом меню нажмите "Клиенты" (🧑‍🤝‍🧑)
4. Используйте поиск и сортировку для анализа клиентской базы

## Безопасность

- ✅ Доступ только для владельцев ресторана и сотрудников
- ✅ Пароли клиентов не отображаются
- ✅ Проверка прав доступа на уровне API

## Статистика

На странице отображаются три основных метрики:
1. **Всего клиентов** - общее количество зарегистрированных пользователей
2. **Всего заказов** - суммарное количество заказов от всех клиентов
3. **Общая сумма** - общая выручка от всех клиентов
