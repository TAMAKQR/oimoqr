# 🎨 Руководство по боковому меню

## Обзор

Боковое меню - это новая навигационная панель, которая делает работу с системой QR Menu более удобной и интуитивной.

## Навигация

### 🏠 Главная

Главная панель управления с обзором ресторана и быстрым доступом к основным функциям.

### 📝 Меню

Управление меню вашего ресторана:

- Добавление и редактирование категорий
- Создание блюд
- Управление ценами и описаниями
- Загрузка фотографий блюд

### ⚙️ Настройки

Настройки вашего ресторана (доступно только владельцам):

- Основная информация
- Логотип и баннеры
- Контакты и социальные сети
- Настройки доставки
- График работы

### 🌐 Языки

Управление языками меню (доступно только владельцам):

- Добавление языков
- Перевод блюд и категорий
- Установка языка по умолчанию

### 👥 Персонал

Управление сотрудниками ресторана (доступно только владельцам):

- Добавление менеджеров
- Управление доступом
- Удаление сотрудников

### 👨‍💼 Админ-панель

Административная панель (только для системных администраторов):

- Управление пользователями
- Управление подписками
- Просмотр статистики

### 💰 Тарифы

Управление тарифными планами (только для системных администраторов):

- Создание тарифов
- Редактирование цен
- Настройка пробного периода

## Использование на разных устройствах

### 💻 Десктоп (ноутбук, компьютер)

Боковое меню всегда видно слева:

- Автоматически разворачивается при загрузке
- Можно свернуть, нажав на стрелку ← вверху
- В свернутом виде показывает только иконки
- Активный раздел подсвечен голубым цветом

**Совет:** Сверните меню для большей рабочей области, иконки помогут быстро найти нужный раздел.

### 📱 Мобильные устройства (телефон, планшет)

Боковое меню скрыто по умолчанию:

- Нажмите кнопку ☰ внизу справа для открытия меню
- Выберите нужный раздел - меню автоматически закроется
- Или нажмите на затемненную область для закрытия меню
- Нажмите ✕ для закрытия меню

**Совет:** Меню автоматически закрывается после выбора раздела, чтобы не загромождать экран.

## Визуальные подсказки

### Цвета

- 🔵 **Голубой фон** - активный раздел (вы здесь)
- ⚪ **Белый фон** - доступные разделы
- 🔘 **Серый** - скрытые разделы (нет доступа)

### Иконки в меню

- 🏠 - Главная
- 📝 - Меню
- ⚙️ - Настройки
- 🌐 - Языки
- 👥 - Персонал
- 👨‍💼 - Админ
- 💰 - Тарифы

### Информация о пользователе

Внизу бокового меню (на десктопе) отображается:

- Первая буква вашего имени в круглом аватаре
- Ваше имя
- Email

## Горячие клавиши (будущее обновление)

В планах добавить:

- `Alt + 1` - Главная
- `Alt + 2` - Меню
- `Alt + 3` - Настройки
- `Esc` - Закрыть меню на мобильном

## Решение проблем

### Меню не открывается на мобильном

1. Убедитесь, что JavaScript включен в браузере
2. Попробуйте перезагрузить страницу (F5)
3. Очистите кеш браузера

### Меню закрывает контент на десктопе

1. Проверьте размер окна браузера (должен быть больше 1024px)
2. Сверните меню, нажав на стрелку ←
3. Увеличьте масштаб окна браузера

### Не вижу некоторые разделы

Это нормально! Разделы показываются в зависимости от ваших прав:

- **Владельцы** - видят все разделы своих ресторанов
- **Менеджеры** - видят только Главную и Меню
- **Администраторы** - видят админ-панель и тарифы
