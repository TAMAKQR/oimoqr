﻿# 📍 Настройка геолокации и выбора ближайшего ресторана

> ⚠️ **СТАТУС:** Функция определения геолокации для клиентов **ОТКЛЮЧЕНА**.
> Backend API и поля в БД готовы для будущего использования как для ресторанов, так и для магазинов.

## 🎯 Что было добавлено

Подготовлена система определения ближайшей точки обслуживания (ресторана или магазина) для пользователей с учетом геолокации и зон доставки.

### ✨ Новые функции:

1. **Геолокация пользователя**

   - Автоматическое определение координат через GPS браузера
   - Возможность ввода адреса вручную (требует интеграции Geocoding API)

2. **Поиск ближайших ресторанов**

   - Расчет расстояния по формуле Haversine
   - Сортировка заведений по расстоянию
   - Проверка зон доставки

3. **Зоны доставки**

   - Настраиваемый радиус доставки для каждого заведения
   - Автоматическая проверка доступности доставки

4. **База данных клиентов**
   - Сохранение адресов для авторизованных пользователей
   - История заказов

## 🗄️ Изменения в базе данных

### Модель `Restaurant`

Добавлены поля:

- `latitude: Float?` - Широта ресторана
- `longitude: Float?` - Долгота заведения
- `deliveryRadius: Float?` - Радиус доставки в км

### Модель `Order`

Добавлены поля:

- `deliveryAddress: String?` - Адрес доставки
- `deliveryLatitude: Float?` - Координаты доставки
- `deliveryLongitude: Float?` - Координаты доставки
- `customerId: String?` - Связь с клиентом

### Новые модели:

**Customer** - Клиенты ресторанов

- `id` - ID клиента
- `phone` - Телефон (уникальный)
- `name` - Имя
- `email` - Email
- `savedAddresses` - Сохраненные адреса
- `orders` - Заказы

**CustomerAddress** - Сохраненные адреса

- `id` - ID адреса
- `customerId` - ID клиента
- `address` - Адрес (текст)
- `latitude` - Широта
- `longitude` - Долгота
- `label` - Метка ("Дом", "Работа")
- `isDefault` - Адрес по умолчанию

## 🔧 API Endpoints

### Поиск ближайших ресторанов

```http
GET /api/geolocation/nearby?latitude=55.7558&longitude=37.6173&maxDistance=50
```

**Параметры:**

- `latitude` - Широта пользователя (обязательно)
- `longitude` - Долгота пользователя (обязательно)
- `maxDistance` - Максимальное расстояние в км (по умолчанию: 50)

**Ответ:**

```json
{
  "userLocation": {
    "latitude": 55.7558,
    "longitude": 37.6173
  },
  "count": 3,
  "restaurants": [
    {
      "id": "...",
      "name": "Ресторан 1",
      "distance": 1.23,
      "isInDeliveryZone": true,
      "deliveryAvailable": true,
      "deliveryFee": 300,
      "deliveryRadius": 5
    }
  ]
}
```

### Найти ближайший ресторан

```http
GET /api/geolocation/nearest?latitude=55.7558&longitude=37.6173
```

### Проверить доступность доставки

```http
GET /api/geolocation/check-delivery?restaurantId=xxx&latitude=55.7558&longitude=37.6173
```

## 👨‍💼 Настройка для владельцев ресторанов

### Как установить координаты ресторана:

1. Перейти в **Настройки ресторана** (`/settings`)
2. Раздел **"Настройки доставки"**
3. Включить доставку (галочка)
4. Прокрутить до **"Геолокация и зона доставки"**
5. Указать:
   - **Широта (Latitude)** - например: `55.751244`
   - **Долгота (Longitude)** - например: `37.618423`
   - **Радиус доставки (км)** - например: `5`

### Как найти координаты:

#### Google Maps:

1. Открыть [Google Maps](https://www.google.com/maps)
2. Найти ваш ресторан
3. Кликнуть правой кнопкой мыши на точку
4. Выбрать первую строку (координаты) - они скопируются
5. Формат: `55.751244, 37.618423`

#### Яндекс Карты:

1. Открыть [Яндекс Карты](https://yandex.ru/maps)
2. Найти ваш ресторан
3. Кликнуть правой кнопкой мыши
4. Выбрать "Что здесь?"
5. Внизу появятся координаты

## ⚠️ Важные замечания

1. **Браузерная геолокация** требует HTTPS (кроме localhost)
2. **Точность GPS** может варьироваться (обычно ±10-50 метров)
3. **Формула Haversine** дает расстояние "по прямой", не учитывая дороги
4. **Координаты** должны быть в формате Decimal Degrees (не DMS)
5. **Радиус доставки** - это приблизительное значение

## 🆘 Решение проблем

### Проблема: Геолокация не работает

**Решение:**

- Убедитесь что используется HTTPS или localhost
- Проверьте разрешения браузера
- Попробуйте другой браузер

### Проблема: Рестораны не находятся

**Решение:**

- Проверьте что у ресторанов установлены координаты
- Увеличьте `maxDistance` параметр
- Проверьте что координаты корректны

### Проблема: Неправильное расстояние

**Решение:**

- Проверьте формат координат (Decimal Degrees)
- Убедитесь что широта и долгота не перепутаны
- Проверьте что `deliveryRadius` в километрах
