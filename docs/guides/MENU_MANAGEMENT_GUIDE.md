# 📝 Руководство по управлению меню

## Обзор

Система управления меню позволяет владельцам ресторанов легко добавлять, редактировать и удалять категории и блюда через веб-интерфейс.

---

## 🚀 Быстрый старт

1. **Войдите в систему** как владелец ресторана:

   - Email: `test@restaurant.com`
   - Пароль: `test123`

2. **Перейдите в Dashboard**: http://localhost:5173/dashboard

3. **Нажмите "Редактировать меню"** или перейдите на: http://localhost:5173/menu-management

---

## 📂 Управление категориями

### Создать категорию

1. Нажмите кнопку **"+ Добавить категорию"**
2. Заполните форму:
   - **Название**: Например, "Горячие блюда"
   - **Порядок сортировки**: Число для определения порядка отображения (0, 1, 2...)
3. Нажмите **"Сохранить"**

### Редактировать категорию

1. Найдите категорию в списке
2. Нажмите кнопку **✏️** (карандаш)
3. Измените данные
4. Нажмите **"Сохранить"**

### Удалить категорию

1. Найдите категорию в списке
2. Нажмите кнопку **🗑️** (корзина)
3. Подтвердите удаление

⚠️ **Внимание**: При удалении категории удаляются все блюда в ней!

### Развернуть/свернуть категорию

- Нажмите на стрелку **▶** или **▼** рядом с названием категории
- Это покажет или скроет список блюд в категории

---

## 🍽️ Управление блюдами

### Создать блюдо

1. Разверните нужную категорию
2. Нажмите кнопку **"+ Блюдо"**
3. Заполните форму:
   - **Название**: Например, "Борщ украинский"
   - **Описание**: Подробное описание блюда
   - **Цена**: В тенге (например, 2500)
   - **Фото**: Выберите изображение блюда
4. Нажмите **"Сохранить"**

### Редактировать блюдо

1. Найдите блюдо в списке
2. Нажмите кнопку **✏️** (карандаш)
3. Измените данные
4. Нажмите **"Сохранить"**

### Удалить блюдо

1. Найдите блюдо в списке
2. Нажмите кнопку **🗑️** (корзина)
3. Подтвердите удаление

### Загрузить фото блюда

- При создании или редактировании блюда выберите файл изображения
- Рекомендуемый размер: 800x600 пикселей
- Форматы: JPG, PNG, WebP
- Максимальный размер: 5 МБ

## ⚙️ Настройки ресторана

Перейдите на страницу настроек: http://localhost:5173/settings

### Основная информация

- **Название ресторана**: Отображается в меню
- **Описание**: Краткое описание вашего заведения
- **Адрес**: Физический адрес ресторана
- **Телефон**: Контактный номер

### Баннер

- Загрузите баннер для главной страницы меню
- Рекомендуемый размер: 1200x400 пикселей
- Используйте для акций и специальных предложений

### Социальные сети

- **WhatsApp**: Номер для приема заказов (формат: +77771234567)
- **Instagram**: Ваш аккаунт (например, @restaurant)
- **Facebook**: Ссылка на страницу

### Настройки доставки

- **Включить доставку**: Чекбокс для активации доставки
- **Стоимость доставки**: Фиксированная цена доставки в тенге
- **Минимальная сумма заказа**: Минимальная сумма для оформления заказа

❌ **Не делайте**:

- Не используйте сложные термины
- Не забывайте про грамматику

### Цены

✅ **Делайте**:

- Указывайте точные цены
- Обновляйте цены регулярно
- Используйте круглые числа (2500 вместо 2499)

❌ **Не делайте**:

- Не оставляйте старые цены
- Не забывайте про НДС (если применимо)

### Структура меню

✅ **Делайте**:

- Группируйте блюда логично
- Используйте понятные названия категорий
- Сортируйте от популярных к менее популярным

❌ **Не делайте**:

- Не создавайте слишком много категорий
- Не смешивайте разные типы блюд в одной категории
- Не дублируйте блюда

## 🔧 Технические детали

### API Endpoints

```
GET    /api/restaurants/:id/categories     - Получить категории
POST   /api/categories                     - Создать категорию
PUT    /api/categories/:id                 - Обновить категорию
DELETE /api/categories/:id                 - Удалить категорию

GET    /api/categories/:id/dishes          - Получить блюда категории
POST   /api/dishes                         - Создать блюдо
PUT    /api/dishes/:id                     - Обновить блюдо
DELETE /api/dishes/:id                     - Удалить блюдо
POST   /api/dishes/:id/upload-image        - Загрузить фото блюда

PUT    /api/restaurants/:id                - Обновить ресторан
POST   /api/restaurants/:id/upload-banner  - Загрузить баннер
```

### Структура данных

**Category**:

```javascript
{
  id: number,
  name: string,
  sortOrder: number,
  restaurantId: number,
  createdAt: datetime,
  updatedAt: datetime
}
```

**Dish**:

```javascript
{
  id: number,
  name: string,
  description: string,
  price: decimal,
  imageUrl: string,
  categoryId: number,
  createdAt: datetime,
  updatedAt: datetime
}
```

## 🐛 Решение проблем

### Кнопки не работают

1. Проверьте, что вы вошли в систему
2. Откройте консоль браузера (F12)
3. Проверьте наличие ошибок JavaScript
4. Убедитесь, что backend запущен

### Изображения не загружаются

1. Проверьте размер файла (макс. 5 МБ)
2. Проверьте формат (JPG, PNG, WebP)
3. Убедитесь, что папка `backend/uploads` существует
4. Проверьте права доступа к папке

### Изменения не сохраняются

1. Проверьте подключение к интернету
2. Откройте Network tab в DevTools
3. Проверьте статус HTTP запросов
4. Убедитесь, что база данных доступна

### Ошибка 401 Unauthorized

1. Выйдите из системы
2. Войдите заново
3. Проверьте срок действия токена (7 дней)
