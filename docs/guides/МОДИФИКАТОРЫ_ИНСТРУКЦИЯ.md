# 📝 Как добавлять модификаторы к блюдам

## Что такое модификаторы?

**Модификаторы** — это дополнительные опции к блюду, которые клиент может выбрать при заказе. Например:

- 🧀 Дополнительный сыр (+50₽)
- 🥓 Бекон (+80₽)
- 🌶️ Острый соус (бесплатно)
- 🍔 Большая порция (+100₽)

---

## 🎯 Как добавить модификаторы к блюду

### Шаг 1: Откройте управление меню

1. Войдите в свой аккаунт
2. Перейдите в **Дашборд**
3. Нажмите **"Управление меню"**

### Шаг 2: Создайте или отредактируйте блюдо

**Вариант А: Создание нового блюда**

1. Раскройте нужную категорию (нажмите ▶)
2. Нажмите кнопку **"+ Блюдо"**
3. Заполните основную информацию:
   - Название блюда
   - Описание
   - Цена
   - Фото (опционально)

**Вариант Б: Редактирование существующего блюда**

1. Раскройте категорию с нужным блюдом
2. Найдите блюдо в списке
3. Нажмите кнопку **✏️** (редактировать)

### Шаг 3: Добавьте модификаторы

В форме блюда найдите секцию **"Модификаторы (добавки)"** внизу формы.

#### Добавление модификатора:

1. **Введите название** модификатора (например: "Дополнительный сыр")
2. **Введите цену** (например: 50)
   - Если модификатор бесплатный, оставьте 0 или пустым
3. Нажмите **"+ Добавить"**

#### Быстрое добавление:

- Можно нажать **Enter** после ввода цены для быстрого добавления

#### Удаление модификатора:

- Нажмите 🗑️ рядом с модификатором, который хотите удалить

### Шаг 4: Сохраните блюдо

Нажмите кнопку **"Сохранить"** внизу формы.

---

## 📱 Как это выглядит для клиента

Когда клиент открывает ваше меню:

1. **Нажимает на блюдо** → Открывается модальное окно
2. **Видит список модификаторов** с чекбоксами
3. **Выбирает нужные добавки** (можно несколько)
4. **Видит итоговую цену** (базовая цена + выбранные модификаторы)
5. **Добавляет в корзину** с выбранными модификаторами

### Пример:

```
🍕 Пицца Маргарита - 500₽

Дополнительно:
☐ Дополнительный сыр +50₽
☐ Бекон +80₽
☐ Грибы +40₽
☐ Острый соус (бесплатно)

Итого: 500₽
```

Если клиент выберет "Дополнительный сыр" и "Бекон":

```
Итого: 630₽ (500 + 50 + 80)
```

## ⚠️ Важные моменты

1. **Модификаторы сохраняются только после сохранения блюда**

   - Если закроете форму без сохранения, модификаторы не сохранятся

2. **Можно добавлять модификаторы к существующим блюдам**

   - Просто отредактируйте блюдо и добавьте модификаторы

3. **Удаление модификатора из существующего блюда**

   - Требует подтверждения
   - Удаляется сразу из базы данных

4. **Цена модификатора может быть 0**

   - Для бесплатных опций (например, "Без лука")

5. **Модификаторы отображаются в порядке добавления**
   - Добавляйте их в том порядке, в котором хотите показать клиентам

## 🔧 Технические детали

### API эндпоинты:

- `POST /api/dishes/:dishId/modifiers` - Создать модификатор
- `PUT /api/dishes/modifiers/:id` - Обновить модификатор
- `DELETE /api/dishes/modifiers/:id` - Удалить модификатор

### База данных:

Модификаторы хранятся в таблице `modifiers` со связью с блюдом через `dishId`.
