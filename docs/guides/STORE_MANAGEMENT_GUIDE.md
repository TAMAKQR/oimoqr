# 🛍️ Руководство по управлению магазином

> **Важно:** Это руководство предназначено для заведений с типом бизнеса **"Онлайн-магазин"**. Для управления меню в **"Ресторане"** используйте соответствующий раздел.

## Обзор

Система управления магазином позволяет владельцам легко добавлять, редактировать и управлять товарами, их вариантами и остатками на складе через веб-интерфейс.

---

## 🚀 Быстрый старт (Планируемый интерфейс)

1. **Войдите в систему** как владелец магазина.
2. **Перейдите в Dashboard**: `https://oimoqr.com/dashboard`
3. **Нажмите "Управление магазином"** или перейдите на: `https://oimoqr.com/store-management`

---

## 📂 Управление категориями товаров

### Создать категорию

1. Нажмите кнопку **"+ Добавить категорию"**.
2. Заполните форму:
   - **Название**: Например, "Электроника", "Одежда".
   - **Описание**: Краткое описание категории.
   - **Порядок сортировки**: Число для порядка отображения.
3. Нажмите **"Сохранить"**.

---

## 📦 Управление товарами

### Создать товар

1. Перейдите в нужную категорию и нажмите **"+ Добавить товар"**.
2. Заполните основную информацию:
   - **Название**: Например, "Смартфон Pro X".
   - **Описание**: Подробное описание товара, характеристики.
   - **Артикул (SKU)**: Уникальный код товара, например, `IPH-15-PRO-BLK`.
   - **Цена**: Основная цена продажи.
   - **Цена для сравнения**: Старая цена, которая будет зачеркнута.
   - **Фото**: Загрузите одно или несколько изображений.

3. Настройте складской учет:
   - **Отслеживать остатки**: Включите, чтобы система следила за количеством.
   - **Количество на складе**: Укажите начальное количество.

4. Нажмите **"Сохранить"**.

### Добавить варианты товара (например, цвет и размер)

1. Откройте созданный товар для редактирования.
2. Перейдите на вкладку **"Варианты"**.
3. Нажмите **"Добавить вариант"**.
4. Заполните поля для варианта:
   - **Название**: Например, "Цвет: Синий, Память: 256GB".
   - **Артикул (SKU)**: Уникальный артикул для этого варианта.
   - **Цена**: Если цена варианта отличается от основной.
   - **Количество на складе**: Остаток именно этого варианта.
   - **Опции (JSON)**: `{"color": "Blue", "storage": "256GB"}`.

## 📈 Управление остатками

Будет создана отдельная страница `/store-inventory` для быстрого обновления остатков всех товаров и их вариантов в виде таблицы.

| Товар / Вариант | Артикул | Остаток | Действие |
|---|---|---|---|
| Смартфон Pro X | IPH-15-PRO-BLK | 50 | [ +/- ] |
| > Цвет: Синий | IPH-15-PRO-BLU | 20 | [ +/- ] |

## 🔧 Технические детали

### API Endpoints

```
GET    /api/products/categories/:restaurantId   - Получить категории товаров
POST   /api/products/categories                 - Создать категорию
PUT    /api/products/categories/:id             - Обновить категорию

GET    /api/products/restaurant/:restaurantId   - Получить все товары
POST   /api/products                            - Создать товар
PUT    /api/products/:id                        - Обновить товар
PATCH  /api/products/:id/stock                  - Обновить остатки
```

### Структура данных

**Product**:
```javascript
{
  id: string,
  name: string,
  description: string,
  sku: string,
  price: float,
  compareAtPrice: float,
  stockQuantity: int,
  trackInventory: boolean,
  variants: ProductVariant[]
}
```

**ProductVariant**:
```javascript
{
  id: string,
  name: string, // "Размер: L, Цвет: Красный"
  sku: string,
  price: float,
  stockQuantity: int,
  options: string // JSON: {"size": "L", "color": "Red"}
}
```
