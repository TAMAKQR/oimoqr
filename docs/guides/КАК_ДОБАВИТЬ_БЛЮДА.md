# 🍽️ Как добавить блюда в меню

## Пошаговая инструкция

### Шаг 1: Откройте страницу управления меню

1. Войдите в систему: http://localhost:5173/login
2. Перейдите в Dashboard
3. Нажмите кнопку **"Редактировать меню"**

---

### Шаг 2: Создайте категорию (если еще не создали)

1. Нажмите кнопку **"+ Добавить категорию"** (справа вверху)
2. Введите название (например: "Супы", "Салаты", "Горячие блюда")
3. Нажмите **"Сохранить"**

```
┌─────────────────────────────────────────────────┐
│  Управление меню          [+ Добавить категорию]│
├─────────────────────────────────────────────────┤
│                                                  │
│  ▶ Супы                    [+ Блюдо] [✏️] [🗑️]  │
│                                                  │
│  ▶ Салаты                  [+ Блюдо] [✏️] [🗑️]  │
│                                                  │
└─────────────────────────────────────────────────┘
```

---

### Шаг 3: Добавьте блюдо в категорию

**Есть 2 способа:**

#### Способ 1: Кнопка "+ Блюдо"

1. Найдите нужную категорию
2. Нажмите кнопку **"+ Блюдо"** справа от названия категории
3. Откроется форма добавления блюда

#### Способ 2: Раскрыть категорию

1. Нажмите на стрелку **▶** слева от названия категории
2. Категория раскроется и покажет список блюд
3. Нажмите **"+ Блюдо"** внутри категории

```
┌─────────────────────────────────────────────────┐
│  ▼ Супы (3 блюда)          [+ Блюдо] [✏️] [🗑️]  │
│     ┌───────────────────────────────────────┐   │
│     │ [фото] Борщ                           │   │
│     │        Традиционный украинский суп    │   │
│     │        1200 ₸              [✏️] [🗑️]  │   │
│     ├───────────────────────────────────────┤   │
│     │ [фото] Солянка                        │   │
│     │        Мясная солянка                 │   │
│     │        1500 ₸              [✏️] [🗑️]  │   │
│     └───────────────────────────────────────┘   │
└─────────────────────────────────────────────────┘
```

---

### Шаг 4: Заполните форму блюда

В открывшейся форме введите:

1. **Название блюда** (обязательно)

   - Например: "Борщ", "Цезарь", "Стейк"

2. **Описание** (необязательно)

   - Например: "Традиционный украинский суп с мясом"

3. **Цена** (обязательно)

   - Например: 1200

4. **Фото блюда** (необязательно)

   - Нажмите "Выбрать файл"
   - Выберите фото с компьютера
   - Увидите превью фото

5. Нажмите **"Сохранить"**

```
┌─────────────────────────────────────┐
│  Новое блюдо                   [×]  │
├─────────────────────────────────────┤
│                                      │
│  Название: [Борщ____________]       │
│                                      │
│  Описание: [Традиционный___]        │
│            [украинский суп_]        │
│                                      │
│  Цена: [1200_______] ₸              │
│                                      │
│  Фото: [Выбрать файл]               │
│        [Превью фото]                │
│                                      │
│  [Отмена]        [Сохранить]        │
└─────────────────────────────────────┘
```

---

## ✅ Проверка результата

После сохранения:

1. Блюдо появится в списке категории
2. Вы увидите фото, название, описание и цену
3. Можете редактировать (✏️) или удалить (🗑️) блюдо

---

## 🔍 Где сохраняются данные?

### База данных (Render PostgreSQL PostgreSQL)

**Категории** сохраняются в таблице `Category`:

- id
- name (название)
- sortOrder (порядок)
- restaurantId (ваш ресторан)
- createdAt (дата создания)

**Блюда** сохраняются в таблице `Dish`:

- id
- name (название)
- description (описание)
- price (цена)
- imageUrl (ссылка на фото)
- categoryId (категория)
- createdAt (дата создания)

**Фото** сохраняются:

- На сервере: `backend/uploads/dishes/`
- В БД хранится только путь: `/uploads/dishes/filename.jpg`

## 🐛 Если что-то не работает

### 1. Категория не сохраняется

**Проверьте:**

- Открыта ли консоль браузера (F12)
- Есть ли ошибки в консоли?
- Работает ли backend (http://localhost:5000/health)

**Решение:**

```powershell
# Перезапустите backend
cd backend
npm run dev
```

### 2. Не видно кнопку "+ Блюдо"

**Причина:** Категория не раскрыта

**Решение:**

1. Нажмите на стрелку ▶ слева от категории
2. Или нажмите "+ Блюдо" справа от названия категории

### 3. Фото не загружается

**Проверьте:**

- Размер файла (должен быть < 5MB)
- Формат файла (jpg, jpeg, png, gif, webp)
- Права на папку `backend/uploads/dishes/`

**Решение:**

```powershell
# Создайте папку если её нет
New-Item -ItemType Directory -Path "d:\QR MENU\backend\uploads\dishes" -Force
```

### 4. Блюдо не появляется в списке

**Причина:** Страница не обновилась

**Решение:**

1. Обновите страницу (F5)
2. Или раскройте/закройте категорию

## 💡 Полезные советы

### Порядок категорий

- Используйте поле "Порядок сортировки"
- Меньшее число = выше в списке
- Например: Супы=1, Салаты=2, Горячие=3

### Качественные фото

- Используйте хорошие фото блюд
- Рекомендуемый размер: 800x600 пикселей
- Формат: JPG или PNG
- Размер файла: до 2MB

### Описания блюд

- Укажите состав блюда
- Укажите вес/объем
- Укажите особенности (острое, вегетарианское и т.д.)
