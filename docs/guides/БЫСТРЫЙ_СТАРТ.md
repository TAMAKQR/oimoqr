**Запустите ваш проект OimoQR за 5 минут!**

---

## 🚀 Локальный запуск (5 минут)

### 1. Установите зависимости

```powershell
npm run install:all
```

### 2. Настройте базу данных

```powershell
cd backend
npx prisma migrate dev
npm run seed
cd ..
```

### 3. Запустите приложение

```powershell
npm run dev
```

### 4. Откройте в браузере

- **Frontend**: http://localhost:5173
- **Backend**: http://localhost:5000
- **Тестовое меню**: http://localhost:5173/menu/testrestaurant

### 5. Войдите

```
Email: test@restaurant.com
Password: test123
```

## 🌐 Деплой на production (30 минут)

### Шаг 1: Render PostgreSQL (5 мин)

1. Зайдите на [Render PostgreSQL.com](https://Render PostgreSQL.com)
2. Создайте проект `oimoqr-db`
3. Скопируйте `DATABASE_URL`

### Шаг 2: Render (10 мин)

1. Зайдите на [render.com](https://render.com)
2. Создайте Web Service `oimoqr-backend`
3. Подключите GitHub
4. Добавьте environment variables
5. Deploy!

### Шаг 3: Vercel (10 мин)

1. Зайдите на [vercel.com](https://vercel.com)
2. Импортируйте проект `oimoqr`
3. Добавьте `VITE_API_URL`
4. Deploy!
5. Добавьте домены: `oimoqr.com`, `*.oimoqr.com`

### Шаг 4: DNS (5 мин)

```
A      @    76.76.21.21
CNAME  www  cname.vercel-dns.com
CNAME  api  ваш-проект.onrender.com
CNAME  *    cname.vercel-dns.com
```
